## 学完应能回答

1. 第 1 天：哪些环节由代码控制，哪些交给模型？
2. 第 2 天：召回不到和召回到了但答错如何区分？
3. 第 3 天：工具参数谁校验，权限谁检查，循环谁终止？
4. 第 4 天：会话记录、任务状态、长期记忆为何需要分别管理？
5. 第 5 天：检索好坏、回答质量、系统稳定性分别用什么指标？
6. 第 6 天：模型 API 不通时，用户看到什么、Trace 留下什么？
7. 第 7 天：你的演示里哪些是真实做过，哪些只是未来规划？

学习优先级：API 连通与工具协议 > 正确闭环 > 状态与评测 > 向量检索升级 > 图编排框架。框架升级带来的 API 变化，不应阻挡你理解消息和工具执行流程。
