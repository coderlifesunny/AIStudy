# 第1天：实操任务与验收

1. 阅读官方资源中 Agent 设计文章的 workflow/agent 部分（30 分钟）。
2. 在本地准备 JDK 和 API 账号；密钥只放环境变量，不写入笔记。
3. 用供应商控制台发一次普通请求，记录模型名、输入输出 token、耗时和失败状态；暂不要求写完整服务。
4. 比较“自由回答部署问题”和“只基于给定三行证据回答”，观察是否仍可能出现错误。
5. 写 300–500 字笔记，解释 Agent、Chat、Workflow 和工具执行边界。

## 验收

- [ ] 能画出“用户 → Java → 模型 API → Java → 用户”。
- [ ] 能在 60 秒内解释为什么模型不能直接操作本地工具。
- [ ] 请求记录中没有密钥；不能把一次成功回答视为系统可靠。
