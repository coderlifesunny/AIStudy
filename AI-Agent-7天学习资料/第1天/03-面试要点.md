# 第1天：面试要点

回答示例用于理解；涉及个人经历和成果时，请用真实内容替换。

## 1. 什么是 Agent？

参考回答：在目标驱动的执行循环中，由模型选择下一步动作或工具，应用执行动作并将结果反馈给模型。工程上还要有状态、权限、预算和终止条件。我的项目只开放只读检索，最多执行两次工具。

追问与易错点：聊天产品也可能有 Agent 能力，不按界面判断。

## 2. 为什么需要工具？

参考回答：模型参数里没有实时且完整的企业事实，工具可以访问授权范围内的文档或服务。模型返回工具名和参数，实际调用由应用完成。

追问与易错点：不要把模型生成 JSON 等同于执行完成。

## 3. 低 temperature 能消除幻觉吗？

参考回答：不能。它主要影响采样，事实正确性还依赖证据质量、任务理解和结果验证。我用固定样本检查，而非只调温度。

追问与易错点：不要承诺输出完全确定。

## 4. 什么时候不用 Agent？

参考回答：任务步骤固定且简单时，直接请求或固定 RAG 工作流更省成本、更容易测试。只有需要动态选择工具或补充检索时才增加循环。

追问与易错点：能说明取舍，比给所有功能加 Agent 标签更重要。
