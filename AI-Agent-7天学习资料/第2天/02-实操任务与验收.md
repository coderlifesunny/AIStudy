# 第2天：实操任务与验收

1. 自建三篇脱敏文档：订单发布、回滚、故障排查。每篇 300–800 字，给出明确标题和文档 ID。
2. 手工按章节切分，给每块标注 docId、chunkId、version。
3. 准备 10 个问题，包含原词、同义改写、跨章节和无答案题。
4. 用字符串包含或词项匹配完成基线，记录每题 top3 片段。
5. 可选：调用一次 embedding API，比较“服务挂了”和“服务故障”的语义匹配；此实验不阻塞第 3 天。
6. 画出离线/在线两条链路，写下三类检索失败原因。

## 验收

- [ ] 每个回答证据都可追溯到原文。
- [ ] 10 题都有 expectedChunkIds 或明确无答案标记。
- [ ] 能解释字符数、token 数、向量维度是不同概念。
- [ ] 没有把“相似度高”解释成“答案一定正确”。

## 实验记录

问题 / 应命中片段 / 实际 top3 / 是否命中 / 失败原因 / 改动方案。
