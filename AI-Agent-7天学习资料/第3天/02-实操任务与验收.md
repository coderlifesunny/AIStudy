# 第3天：实操任务与验收

1. 写 `search_documents(query)` 的输入/输出协议，输出 chunkId、title、text 和 version。
2. 先用伪造模型响应测试 Java 分派：合法工具、未知工具、空 query、越界 query。
3. 接入真实 API，观察一次 assistant tool_call → tool result → final answer。
4. 模拟模型连续重复调用，验证达到预算能停止。
5. 保留一份脱敏消息往返记录，说明每条消息的 role 和 tool_call_id。

## 验收

- [ ] 不是依赖模型生成一句“我已检索”就认为工具执行成功。
- [ ] 未知工具无法执行；模型不能传入文件路径或租户 ID 来越权。
- [ ] 重复调用和超预算均有明确结果。
- [ ] 有工具失败案例和 traceId。

首版可以先完成单次调用，第 6 天再实现完整的有限循环。

将完成证据记入 [学习进度与复盘](../学习进度与复盘.md)。
