# 第3天：面试要点

回答示例用于理解；涉及个人经历和成果时，请用真实内容替换。

## 1. 模型真的执行了工具吗？

参考回答：没有。模型输出结构化调用意图，应用校验后执行并返回工具结果。执行成功由应用记录确认。

追问与易错点：工具结果通过调用 ID 对齐。

## 2. 为什么需要编排？

参考回答：一次任务可能经历检索、观察、补查、回答。编排保存当前步骤和结果，并统一停止、超时、错误处理。

追问与易错点：简单任务一个 while 循环就能开始。

## 3. 怎么防止无限循环？

参考回答：在应用层限制工具执行次数、逻辑模型轮次和总 deadline；重复调用可复用结果；最后一轮禁止工具。

追问与易错点：不能仅在 prompt 写“最多两次”。

## 4. 为什么不用复杂框架？

参考回答：当前只有一个只读工具，显式循环更方便理解协议和调试。图编排适合分支、恢复、人工介入增多后的阶段。

追问与易错点：框架选择根据复杂度而非热度。
