# 第4天：实操任务与验收

1. 用 Java record 或 class 定义 Session、AgentRun、ToolExecution。
2. 画状态机，列每条边的触发条件与终态。
3. 在 A 会话问发布问题，在 B 会话问权限问题，再分别追问，检查不串话。
4. 模拟同一会话同时提交两个请求，验证一个返回 409。
5. 缩短 TTL 做一次到期测试，重启服务检查会话丢失行为有明确说明。

## 验收

- [ ] 分得清 sessionId、runId、traceId、tool_call_id。
- [ ] 出错不会永久卡住会话锁。
- [ ] 旧引用不能绕过当前文档访问控制。
- [ ] 内存历史和任务状态都有容量限制。

交付：状态图、状态字段表、两组会话对照记录。
