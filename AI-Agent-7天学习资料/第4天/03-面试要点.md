# 第4天：面试要点

回答示例用于理解；涉及个人经历和成果时，请用真实内容替换。

## 1. Memory 为什么需要？

参考回答：它把当前任务所需历史带回有限的模型上下文。模型 API 本身不会替我的应用保存所有对话，我需要管理裁剪、隔离和生命周期。

追问与易错点：首版不做长期记忆也能闭环。

## 2. Memory 和 State 有何区别？

参考回答：Memory 偏向可供后续使用的信息，State 偏向执行到哪一步、预算和结果。两者可关联，但不宜全塞进一条对话文本。

追问与易错点：说出具体存储字段。

## 3. 如何避免串话？

参考回答：会话关联服务端身份，校验归属；同会话串行，不同会话隔离；工具权限来自服务端身份而非模型参数。

追问与易错点：随机会话 ID 不是鉴权。

## 4. 失败后如何恢复？

参考回答：首版返回明确失败并释放锁，用户重试创建新 run；跨进程恢复需要持久化步骤及幂等策略，不假装已有工作流恢复能力。

追问与易错点：区分会话保留和任务恢复。
