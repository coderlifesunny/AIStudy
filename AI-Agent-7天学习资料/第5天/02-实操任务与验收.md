# 第5天：实操任务与验收

1. 按 20 题分类建立 JSONL 或 Markdown 测试集，填期望事实和证据。
2. 给一次成功和一次失败请求补齐 Trace。
3. 人工逐题评分，记录正确/错误及具体原因；再计算指标。
4. 将重复检索结果、过长历史、一次 429 和一次超时作为故障样本。
5. 写一页评测报告：数据版本、模型、参数、问题数、指标、失败类型、下一步实验。

## 验收

- [ ] 正确率有分母；错误和超时不被悄悄剔除。
- [ ] 引用语义支持人工检查过，不只检查格式。
- [ ] 能用 traceId 定位是哪一次工具或 API 调用失败。
- [ ] 所有“提升了多少”都有可比较的原始记录。

报告结论示例：本轮 20 题中的可回答题为 N，正确 M；此处填真实数值，不预写漂亮成绩。

将完成证据记入 [学习进度与复盘](../学习进度与复盘.md)。
