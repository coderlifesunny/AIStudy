# 第6天：实操任务与验收

1. 完成普通模型 API 调用并隐藏密钥（30–60 分钟）。
2. 完成知识加载、按标题分块和 top3 关键词检索（60 分钟）。
3. 接入工具 Schema 与显式工具循环（60–90 分钟）。
4. 加会话、引用校验、deadline、预算和脱敏日志（60–90 分钟）。
5. 跑至少 5 条冒烟样本；再跑第 5 天固定集，记录未达目标项（45 分钟）。
6. 写 README：启动要求、配置变量、请求示例、数据位置、限制和真实结果（30 分钟）。

## 验收

- [ ] 一条请求中确实出现 tool_calls 和对应 Java 执行记录。
- [ ] 正确答案能回到文档版本及 chunkId。
- [ ] 无证据、坏参数、重复调用、超时都有终态。
- [ ] 同会话并发控制与全局配额生效。
- [ ] 服务只监听本地；没有外露未鉴权接口。
- [ ] 重启会话丢失这一限制写进 README。

如果当天超时，优先完成单轮工具闭环与失败响应，再增加会话。不要用“预计完成”勾选验收项。

将完成证据记入 [学习进度与复盘](../学习进度与复盘.md)。
