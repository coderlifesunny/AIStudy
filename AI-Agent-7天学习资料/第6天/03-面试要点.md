# 第6天：面试要点

回答示例用于理解；涉及个人经历和成果时，请用真实内容替换。

## 1. 为什么选择这个项目？

参考回答：它能把 Java 的接口、状态和稳定性经验与模型工具调用结合，规模小到可以逐条验证，又能展示证据、失败和成本治理。

追问与易错点：先说实际问题，再说技术栈。

## 2. 你项目哪里体现 Agent？

参考回答：模型决定是否检索、用什么查询词以及是否补查；Java 负责白名单执行、回传结果和终止。若实现只有固定先检索后回答，我会称为 RAG 工作流。

追问与易错点：与真实实现保持一致。

## 3. 为什么没上向量库？

参考回答：当前语料很小，先验证协议和工程闭环。关键词检索是基线，改写题召回不足时再以同一评测集比较向量方案。

追问与易错点：承认关键词检索的语义召回限制。

## 4. 能上线生产吗？

参考回答：当前是本地演示版；正式多用户使用还需认证、授权、持久化、并发治理、数据处理规范与运维验证。已有设计不等于已上线。

追问与易错点：不虚构 SLA 或生产用户。
