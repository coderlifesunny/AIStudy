# 第7天：面试复盘与项目表达

目标：理解今天的机制，并能在小型知识库 Agent 中指出它的落点。

## 1. 回答结构

概念题按“定义 → 场景 → 机制 → 限制”回答；项目题按“问题 → 选择 → 链路 → 证据 → 改进”回答。先在 60–90 秒说清主线，再根据追问展开。

## 2. 今天必须串起来的知识

LLM 提供理解与生成；工具提供外部数据；RAG 提供检索证据；状态保存执行过程；会话为多轮补上下文；校验和预算约束输出与行为；评测证明效果；Trace 帮助定位失败。这些是一个系统里的配合关系。

## 3. 五个必备追问

- 为什么工具由模型选择，权限却不能交给模型？
- 为什么不一开始使用向量库和图编排？什么时候会升级？
- 检索没有命中与生成没有忠于证据怎么区分？
- 预算到达后如何停止？重试怎么影响成本？
- 项目有哪些实际结果，哪些还只有方案？

## 4. Java 经验迁移

接口契约对应工具 Schema；数据库授权对应工具与证据访问控制；事务与幂等对应工具副作用管理；链路追踪对应模型与工具 Trace；超时熔断对应外部 API 治理；回归测试对应离线评测。不同之处在于结果有不确定性，必须加语义质量评估。

## 5. 诚实表达与阶段目标

可以说“我完成了本地学习项目，在 N 题固定样本上测得……”，不能改成“公司落地了生产 Agent 平台”。如果还没有代码，就说“目前完成设计并在实现”，用设计决策回答追问，不虚构失败经历。

## 6. 模拟面试流程

1 分钟自我介绍 → 5 分钟项目讲解 → 8 分钟技术追问 → 3 分钟失败案例 → 3 分钟复盘。录音后检查有没有堆概念、无证据指标、职责边界混淆；把最弱两题回到对应日期重练。
