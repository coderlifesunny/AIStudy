# 第7天：实操任务与验收

1. 不看笔记回答本周至少 10 道问题，每题控制在 90 秒内。
2. 按模板填真实完成情况；模型、语料规模、指标均需可核对。
3. 录制 5–8 分钟演示：一条成功、一个拒答、一次故障定位。
4. 画一次白板架构，并在图上指出模型、应用、数据的边界。
5. 准备“最难的问题”和“下一步优化”，必须对应实际记录或明确设计取舍。

## 验收

- [ ] 能在不看稿的情况下解释完整工具往返。
- [ ] 能讲一个实际失败案例，或诚实说明仍在实现。
- [ ] 指标附样本量、日期、模型和测试口径。
- [ ] 能清楚区分个人实验、设计规划、生产经验。

自评分：概念清晰度 / 工程细节 / 证据充分度 / 表达简洁度，各 1–5 分；低于 3 分项回到对应天补练。

将完成证据记入 [学习进度与复盘](../学习进度与复盘.md)。
