# 第7天：面试要点

回答示例用于理解；涉及个人经历和成果时，请用真实内容替换。

## 1. 你为什么做 AI Agent？

参考回答：我希望把已有的 Java 后端能力用于带模型的不确定性系统，先从知识问答工具闭环切入，重点学习工具、状态、评测和稳定性。

追问与易错点：结合自己的真实动机调整。

## 2. 你最擅长什么？

参考回答：用真实经历说明接口设计、数据管理或故障排查，然后举例这些能力如何用于工具校验、会话隔离和 Trace。

追问与易错点：不要只说十年经验就等于擅长。

## 3. 你目前的短板是什么？

参考回答：说明具体短板，例如检索调优和模型评测经验仍少，再说明用固定样本和对照实验补足；不要用伪缺点回答。

追问与易错点：短板与行动对应。

## 4. RAG、Agent、微调是什么关系？

参考回答：RAG 是外部检索增强方式，Agent 是动态决策执行方式，微调是模型适配方式。Agent 可以将 RAG 作为工具，也可以不需要检索；三者并非互相替代。

追问与易错点：能用本项目画出关系。

## 5. 如何做一次可信的项目总结？

参考回答：描述范围、实际功能、数据和测试条件，展示成功与失败，再给出下一步验证计划。所有性能和质量结论都限定在测试范围内。

追问与易错点：不拿规划能力冒充已实现能力。
